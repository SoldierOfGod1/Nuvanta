## Pre-launch Acceptance Criteria

All must pass before any paid traffic.

### Legal & Compliance
- [ ] Business registered (Pty / sole prop documented)
- [ ] Business bank account active
- [ ] PayFast or Ozow merchant account live + R1 test successful
- [ ] POPIA notice published in site footer
- [ ] T&Cs page published in site footer
- [ ] CPA-compliant returns policy (7-day cooling-off, who pays shipping, refund timeline)
- [ ] Privacy policy lists trackers (GA4, Meta, TikTok)
- [ ] VAT registration status documented + price display compliant

### Storefront
- [ ] Domain configured, SSL active, www + apex resolve
- [ ] Mobile load < 3s on 4G (Lighthouse mobile >= 70)
- [ ] Cart persists across browser refresh
- [ ] Checkout completes end-to-end with R1 test order
- [ ] Order confirmation email arrives < 2 min
- [ ] WhatsApp click-to-chat opens correct number on mobile
- [ ] 404 page exists and is branded

### Product Page (single SKU at MVP)
- [ ] >= 4 product photos (1 hero, 3 detail)
- [ ] Price displays VAT-inclusive
- [ ] Delivery time honestly disclosed (2-5 days)
- [ ] Stock status accurate or "ships in X days"
- [ ] Spec table where applicable
- [ ] Add to cart verified: iOS Safari, Android Chrome, desktop Chrome, desktop Firefox

### Tracking & Analytics
- [ ] GA4 connected, real-time view confirms test traffic
- [ ] Meta Pixel fires on PageView, ViewProduct, AddToCart, InitiateCheckout, Purchase
- [ ] TikTok Pixel fires on same five events
- [ ] Conversion API server-side fallback configured (iOS 14.5+ loss)
- [ ] UTM parameters preserved through checkout

### Operations
- [ ] Dropstore test order placed by founder, delivered to founder
- [ ] Returns process tested end-to-end against the test order
- [ ] WhatsApp Business auto-reply configured (business hours, 24hr response cap)
- [ ] orders@nuvanta.co.za auto-responder live
- [ ] Founder has personally tested the product in their own home

## Test Scenarios

### TS1 — Happy path first sale
Mobile -> homepage -> product -> add to cart -> checkout -> PayFast test card
-> order confirmation email -> WhatsApp confirmation -> Dropstore ships -> delivered <= 5 days.

### TS2 — Out of stock after payment captures
Document the recovery flow before launch: refund? backorder? cancellation?

### TS3 — Chargeback dispute
PayFast/Ozow notification path + founder response window + dispute evidence pack.

### TS4 — Return after CPA 7-day window
Policy must explicitly state yes/no/conditional.

### TS5 — Wrong product shipped by Dropstore
Founder's SLA recourse + customer-facing apology + replacement workflow.

### TS6 — Stress: 50 simultaneous AddToCart
Shopify handles. TikTok pixel most likely to drop events under load - verify.

### TS7 — Adversarial: stolen card / fraud order
Payment gateway fraud rules configured + manual review threshold for first 30 days.

### TS8 — Mobile-specific: checkout abandonment on iOS Safari
Known Shopify quirk. Run the funnel on iOS Safari specifically.

## Predicted Failures Week 1

1. **Pixel attribution mismatch** - Meta says 5, GA4 says 3, Shopify says 4.
   Trust Shopify. Don't panic.
2. **Dropstore stockout on winner** - identify backup supplier in advance.
3. **WhatsApp ticket flood** - pre-write 5 quick-reply scripts for the
   predictable questions (delivery time, returns, sizing, payment, refund).
4. **TikTok complaint video** - response template ready before launch.
   Speed > content.
5. **Card decline rate ~12% in SA** - fallback "try another card" UX in
   checkout.

## Go / No-Go

### GO if:
- All CRITICAL acceptance items checked
- TS1 happy path completes with real R1 test
- 5 customer interviews logged (per /office-hours assignment)
- Founder has personally tested the product

### NO-GO if:
- Any legal/compliance item unchecked
- TS1 fails at any step
- Dropstore confirmed lead time > 5 days
- Net contribution margin < R150/unit after full cost stack
